0. Verilog Basics: Absolute Beginner Guide

If you have never written a single line of Verilog before, don't worry! This guide explains every single concept in simple, everyday English with real-life examples so you can ace your lab exam.

💡 What is Verilog? (Hardware vs. Software)

In languages like C or Python, lines of code run one after another, top to bottom, on a CPU. Verilog is completely different: it does NOT run on a CPU. Instead, Verilog is a blueprint for physical electronic circuits.

When you have 3 gates on a breadboard or chip, electricity flows through all 3 gates at the exact same time. Verilog code describes these physical parts connected together, running in parallel!

1. What is a module?

Think of a module as a physical microchip or IC (like an IC 7408 AND gate chip):

  • The header module my_chip(A, B, Y); lists the metal pins sticking out of the chip.
  • The body describes what silicon logic or gates are inside the chip.
  • The end endmodule tells the compiler "this is the end of the chip". (Notice: never put a semicolon after endmodule!).

2. Understanding Inputs: 1-Bit Pins vs Multi-Bit Buses (Vectors)

This is where beginners get confused most often. Let's make it crystal clear:

  • Single-bit inputs — input s0, s1;
    Here, s0 is one single wire carrying either a 0 (0V) or 1 (5V). s1 is another separate single wire.
    Real-life example: Think of two separate wall light switches in your room. Each switch is either ON (1) or OFF (0).
  • Multi-bit bus (vector) — input [3:0] in;
    This is NOT a single wire! The [3:0] notation means a bundle of 4 wires grouped together under the single name in.
    The 4 individual wires inside this cable are called:
    • in[0] — Wire #0 (the first data wire)
    • in[1] — Wire #1 (the second data wire)
    • in[2] — Wire #2 (the third data wire)
    • in[3] — Wire #3 (the fourth data wire)
    Real-life example: Think of a 4-lane highway or a 4-wire ribbon cable. in is the whole highway; in[0] is lane 0, in[1] is lane 1, etc.
  • Multi-bit outputs — output [3:0] out;
    Just like above, this creates 4 output wires: out[0], out[1], out[2], and out[3].

3. wire vs reg (The Simplest Rule)

  • wire: A regular copper wire. It has no memory. If you unplug the voltage, the signal disappears immediately. Used whenever you use assign statements or structural gate primitives.
  • reg: Short for register. It can remember its value like a tiny memory cell. In Verilog, any output modified inside an always block must be declared as reg (e.g. output reg Y;).

4. The Three Types of Verilog Writing (Modeling Styles)

In lab exams, professors often ask you to write a circuit in one of these 3 styles:

1. Dataflow Modeling

You write the mathematical Boolean formula directly using the keyword assign.

assign Y = A & B;

Meaning: "Continuously calculate A AND B and send the voltage to wire Y."

2. Behavioral Modeling

You describe the circuit's behavior algorithmically like software using an always block and if/else or case.

always @(*) Y = A & B;

Meaning: "Whenever any input changes, run this block to update Y." Output MUST be reg!

3. Structural Modeling

You connect physical gates from a library (like placing chips on a breadboard) and connect pins with wires.

and g1(Y, A, B);

Meaning: "Take an AND gate named g1; its output pin is Y, and its input pins are A and B."

5. Verilog Math Operators

  • & — Bitwise AND (Outputs 1 only if both are 1).
  • | — Bitwise OR (Outputs 1 if at least one is 1).
  • ~ — Bitwise NOT / Inverter (Flips 0 to 1 and 1 to 0).
  • ^ — Bitwise XOR (Outputs 1 if inputs are different; 0 if equal).
  • ~^ or ^~ — Bitwise XNOR (Outputs 1 if inputs are equal).

6. Literals (Numbers) in Verilog

Format: <number_of_bits>'b<binary_value>

  • 1'b0: A 1-bit binary number with value 0.
  • 1'b1: A 1-bit binary number with value 1.
  • 2'b00: A 2-bit binary number 00 (decimal 0).
  • 2'b01: A 2-bit binary number 01 (decimal 1).
  • 4'b0000: A 4-bit binary bundle of all zeros.
